## 回顾基础 C# 常量
C# 语言的设计是为了从其他编程语言的经验中受益。C# 编程背后的基本概念即使是最简单的程序也是显而易见的。本质上，一个 C# 程序可以被看作有很多层的洋葱。在 .NET 环境（C# 是其主要语言）中，有从通用到特定的代码层。最外层的最通用层是命名空间。在命名空间内部，你会发现一系列类，类包含方法，方法包含语句。实际上，这是一种简化的视图。当你阅读这本书（以及之后）时，你将看到 .NET 模型包含其他元素。然而，这个精简版的模型目前足够了。

## 命名空间
编程的不同层级帮助你组织程序。即使是初学者，也需要了解一下各个层，因为即使是最基础的程序也会使用它们。将这些层想象成信封上的地址。在给信封写地址时，你会写下特定的信息，例如门号。你还会写城市（更通用）和州（范围更广）。邮政可以通过获取正确的州，然后是城市，然后是正确的区域，最后是房子来递送你的信。C# 语言中的命名空间工作就像这样。C# 中最大的单元是命名空间。命名空间是一个容器，允许你对其他东西分组。此外，你在程序中可以使用的所有东西——包括系统本身以及元素（如文本和按钮）都分在命名空间中。在代码中使用命名空间，你使用 `using` 指令。在代码中定义命名空间，你使用 `namespace` 关键字。

```csharp
namespace MyNamespace
{
    class MyClass
    {
        // 代码写在这里
    }
}
```

# 第三章使用 switch 语句
`switch` 语句用于根据值执行一个代码块。它通常比一系列 `if-else` 语句更具可读性。

```csharp
switch (variable)
{
    case 1:
        // case 1 的代码
        break;
    case 2:
        // case 2 的代码
        break;
    default:
        // 其他情况的代码
        break;
}
```

# 第五章 循环与字符串：猪鼻语程序
循环用于多次重复一个代码块。循环有两种主要类型：`for` 和 `while`。

```csharp
for (int i = 0; i < 5; i++)
{
    Console.WriteLine("Iteration: " + i);
}

int count = 0;
while (count < 5)
{
    Console.WriteLine("Count: " + count);
    count++;
}
```

字符串在 C# 中用于存储文本。

```csharp
string message = "Hello, World!";
Console.WriteLine(message);
```

# 第七章 对象与封装：小生物
对象是 C# 的构建块。封装是隐藏对象内部细节并通过方法暴露它们的实践。

```csharp
public class Dog
{
    private string _name;

    public void Bark()
    {
        Console.WriteLine(_name + " says: Woof!");
    }
}
```

# 第八章 构造函数、继承与
构造函数用于初始化对象。继承允许一个类从另一个类派生属性和方法。

```csharp
public class Animal
{
    public string Name { get; set; }
}

public class Cat : Animal
{
    public void Meow()
    {
        Console.WriteLine("Meow!");
    }
}
```

# 第九章 定器与动画：月球着陆器
定时器用于在特定间隔执行代码。动画涉及创建运动的幻象。

```csharp
using System.Timers;

Timer timer = new Timer(1000);
timer.Elapsed += (s, e) => Console.WriteLine("Tick!");
timer.Start();
```
