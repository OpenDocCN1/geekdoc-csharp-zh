## 执行数学运算

编写执行操作的方法和表达式是非常言而易懂的。例如，如果你想相变量 `x` 和 `y` 的值，在变量声明并赋值后你将使用以下语法。你可以使用 `Console.Write` 函数配合以下语法直接打印结果数字：

```csharp
Console.Write (“The sum is ” + (x + y));
```

记住，你需要将想要执行的算术运算括在括号中。否则，`Console.Write` 函数将把 `x` 和 `y` 的值仅仅视为要写入行的扩展。例如，如果 `x = 1` 且 `y = 2`，结果将是：

```csharp
Console.Write (“The sum is “ + x + y)); /* 相应的输出将是 The sum is 12 */
Console.Write (“The sum is “ + (x + y)); /* 相应的输出将是 The sum is 3 */
```

或者，你可以将结果存储在另一个变量中。这样你就可以避免每次想打印两个变量之和时都添加 `(x + y)`。将其存储在单独变量中还允许你使用它的值执行进一步的操作。

## 简单计算器

在 C# 中创建一个全功能程序的最简单方法是编写一个执行简单数学计算的小程序。利用你学到的关于用户输入和变量的知识，你应该能够获取要执行操作的值。

这是一个允许你对两个数字进行简单数学运算的程序示例：

```csharp
using System;

namespace Calculator
{
    class MainClass
    {
        public static void Main (string[] args)
        {
            int x, y, a, b, c, d;
            Console.WriteLine (“Please insert the 1st number.”);
            x = Convert.ToInt32(Console.ReadLine());
            Console.WriteLine (“Please insert the 2nd number.”);
            y = Convert.ToInt32(Console.ReadLine());
            a = x + y;
            b = x - y;
            c = x * y;
            d = x / y;
            Console.WriteLine (“The sum is “ + a);
            Console.WriteLine (“The difference is “ + b);
            Console.WriteLine (“The product is “ + c);
            Console.WriteLine (“The quotient is “ + d);
        }
    }
}
```

## 其他运算符

在本书的剩余章节中，你还将介绍 C# 中的其他基础运算符。这包括条件、关系和一元运算符，它们可用于循环。首先，让我们看看一些元运算符：

注意：变量 `x` 仅作为操作数的示例，不属于运算符本身。

- `++x` – 该运算符将操作数的值增加 1。
- `--x` – 该运算符将操作数的值减少 1。
- `+x` – 该运算符仅表示操作数的值。
- `-x` – 该运算符将取操作数的负值。

一元运算符之所以这样命名是因为它们只影响所属的单个操作数。这些运算符对于编写条件语句设置循环参数有用。

另一类有运算符是关系运算符，其主要目的是比较两个操作数：

- `==` – 该运算符检查两个操作数是否相等。
- `!=` – 与 `==` 运算符相反，此运算符检查两个操作数是否不等。
- `>` – 该运算符检查左侧操作数是否大于右侧。
- `<` – 该运算符检查左侧操作数是否小于右侧。
- `>=` – 该运算符检查左侧是否大于或等于右侧。
- `<=` – 该运算符检查左侧是否小于或等于右侧。

关系运算符返回布尔值并用于创建条件语句。在创建循环时设置条件参数也有用。

最后，条件运算符是用于检查两个或多个参数的基础运算符。它们返回布尔值取决于操作数的值。这两个运算符是：

- `&&` – 该运算符检查双方是否都为真。如果是，它将产生真的布尔值。
- `||` – 该运算符检查至少有一侧是否为真。例如，表达式 `1 < 2 || 1 > 2` 将返回真的布尔值，因为左侧为真，即使右侧不是。

```csharp
            /* Relational Operators */
            if (x == y)
            {
                Console.WriteLine (“The two numbers are equal.”);
            }
            else if (x < y)
            {
                Console.WriteLine (“The first number is smaller.”);
            }
            else
            {
                Console.WriteLine (“The first number is bigger.”);
            }
            /* Conditional Operators */
            if (x < 0 || y < 0)
            {
                Console.WriteLine (“one of them is negative.”);
                if (x != -2 && y != -2)
                {
                    Console.WriteLine (“None of them is -2.”);
                }
            }
            /* Unary Operators */
            Console.WriteLine (“The increment of the first number is “ + ++x);
            Console.WriteLine (“The decrement of the second number is “ + --y);
            Console.ReadKey();
        }
    }
}
```

## 什么是流程控制？

简单来说，你可以使用流程控制语句来控制程序的方向或过程。与其简单地从上到下运行每一行和方法，你可以告诉程序在任何给定时刻访问哪些特定的内容。

你在上一章使用的 `if-else` 语句是使用布尔逻辑的流程控制示例。如果满足一个条件，将应用后续的方法。为了清晰起见，这里是 C# 中编写 `if-else` 语句的正确语法：

```csharp
if (“在此处插入条件”)
{
    /* 如果满足条件，插入你想要运行的方法 */
}
else if (“在此处插入辅助条件”)
{
    /* 如果不满足第一个条件，可以使用 else if 检查另一个条件并运行其他方法 */
}
else
{
    /* 如果之前的所有条件都不满足，可以运行 else 语句；记住 else 语句是可选的 */
}
```

除了 `if-else` 语句外，在运行结果之前检查特定条件的更简单方法是使用三元运算符 (`?`)。使用此运算符，你可以根据条件返回的布尔值初始化另一个变量的值。使用此运算符的正确语法如下：

`<条件> ? <如果为真的结果> : <如果为假的结果>`

例如，`if-else`：
```csharp
if (x != y)
    z = 1;
else
    z = 2;
```
等于：
`z = (x != y) ? 1 : 2;`

在 C# 语言中，使用条件语句控制运行哪些代码行被称为分支。除了使用三元运算符和 `if-else` 语句外，你还可以使用 `switch` 语句来控制程序的运行。

## Switch

通过 `switch` 语句，你可以编写具有不同 case 的程序，这些 case 根据 `switch` 表达式中变量的值触发。以下是 `switch` 语句的样式：

```csharp
switch (“statement”)
{
    case 1: /* 如果 switch 变量等于 1，将发生什么 */
        break;
    case 2: /* 如果 switch 变量等于 2，将发生什么 */
        break;
    default: /* 如果 switch 变量不等于上述任何 case，将发生什么 */
        break;
}
```

同时请记住，你需要在每个 case 结束操作的地方使用 `break`。否则，程序将继续执行剩余的 case，从而违背使用 `switch` 流程控制语句的目的。此外，注意 `default` 等于 `if-else` 语句中的 `else` 语句。

这是一个简单的示例，要求用户从给定范围内输入一个数字并给出相应的响应：

```csharp
char x;
Console.WriteLine (“Insert a letter from A-C.”);
x = Convert.ToChar(Console.ReadLine());
x = Char.ToUpper(x);
switch (x)
{
    case ‘A’:
    {
        Console.WriteLine (“You put A.”);
        break;
    }
    case ‘B’:
    {
        Console.WriteLine (“You put B.”);
        break;
    }
    case ‘C’:
    {
        Console.WriteLine (“You put C.”);
        break;
    }
    default:
    {
        Console.WriteLine (“Invalid input.”);
        break;
    }
}
```

注意，对于此示例，`x` 的字符输入在 `x = Char.ToUpper(x);` 这一行被转换为大写。记住上述 `switch` 语句中的 case 只检查 `x` 的值是否为大写字母 A、B 或 C 之一。如果用户在不先转换的情况下输入小写 a，case 语句将把用户引导到 `default` 方法。

## 编写循环

创建程序运行方式变化的另一种方法是使用循环。只要满足所需的条件，循环基本上会一直重复其内部的方法。循环还有一个特定的点，在该点会对条件进行更新和重新检查。一旦不再满足要求的条件，循环就会停止，应用程序将恢复。

### While 循环

`while` 循环在运行包含的语句之前先测试条件。利用 `while` 循环的最简单方法是创建一个从 10 开始倒数的程序。它的编写方式如下：

```csharp
int x = 10;
while (x > 0)
{
    Console.WriteLine (x);
}
```

# for 循环

for 循环与 while 循环的主要区别在于，在声明 for 循环本身时，初始化、检查和更新先决变量的参数被包含在内了。结合上面的示例，for 循环的形式如下：

```csharp
for (int x = 10; x > 0; x--)

{
    Console.WriteLine (x);
}
```

# 生成随机数

在 C# 中生成随机数，你需要调用 `Random` 类，该类用于生成随机数的实例。可以使用实例构造函数语法来实现，这需要为实例指定名称以及可选参数。

要创建 `Random` 类的实例，可以使用以下语法：

```csharp
Random <instance name> = new Random ();
```

此外，你还需要实际使用该随机实例的变量。例如，如果你想为变量 `random` 生成一个随机值，你需要使用的语法如下：

```csharp
Random RandomInstance = new Random ();
int random = RandomInstance.Next (1, 101;
```

在这个特定的示例中，随机实例将生成一个 1 到 100 之间的数字，该数字与 `RandomInstance` 一起声明。记住，表达式中的最大值始终比实际值大 1。如果你愿意，可以留空这些参数。

```csharp
using System;

namespace DieRoller

{
    class MainClass
    {
        public static void Main (string[] args)
        {
            char Roll = ‘R’;
            /* 首先，我们初始化 do-while 循环的条件 */
            do {
                Random x = new Random ();
                /* 我们创建了一个名为‘x’的 random 类的实例/对象 */
                int die01 = x.Next (1, 7);
                Console.WriteLine (“The first die rolls “+ die01);
                /* 第一个骰子或变量 die01 的值从 1-6 之间生成并打印 */
                int die02 = x.Next (1, 7);
                Console.WriteLine (“The second die rolls “+ die02);

                Roll = Convert.ToChar (Console.ReadLine ());
                Roll = Char.ToUpper (Roll);

            } while (Roll == ‘R’);
            /* 最后，程序检查变量 roll 的值是否仍为 Y，如果是则将重启 */
        }
```
