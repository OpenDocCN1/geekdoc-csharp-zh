Boxing
The int type of a variable is converted to object type, or value type is converted into reference type, which is known as “Boxing”.
object newVariable = (object) oldVariable;
The int type  of “oldVariable” can be converted to object type of “newVariable”.
Example 1.12
using System;
namespace Boxing{
class Program{
static void Main(string[] args){
int var1 = 100;

Console. WriteLine("The data type of var2 is object type now. ");
Console. ReadLine();
}}}
Output:        The data type of var2 is object type now.
Explanation:
“object var2 = (object)var1;” converts the data type of “var1” from int type to object type var2.

UnBoxing

Delegate
A delegate is a reference type that can be used to encapsulate a named or an anonymous function. Namely a delegate is a type which holds the function’s reference in an object.

public static int myFunction(int a, int b) { }

(2) Declare a delegate function, its arguments should be the same as the arguments of the delegated function, for example:
public delegate int DelegateFun(int a, int b) ;

(3) Create a delegate object, its argument should be the delegated function name, for example:
DelegateFun delegateObj = new DelegateFun(myFunction) ;
// delegateObj is a delegate object
(4) Execute the delegate, for example:
delegateObj(arg1, arg2);    // call delegated function , pass params
